# Atoll development

- Make requested changes on a feature branch and open a pull request against `Mazon3442/Atoll` on GitHub. Do not merge without an explicit request.
- Keep unrelated user changes out of the pull request.
- Use `DESIGN.md` as the visual direction for the island. Preserve custom colors, keyboard operation, and reduced-motion support.
- Validate changes with the relevant .NET tests and render the affected WPF templates. Use a separate artifacts directory while the user's app is running.
