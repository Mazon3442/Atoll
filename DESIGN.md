# Atoll island design

Redesign in progress on `design/system-refresh`: see `docs/design/foundations.md` (shape setting, radius ladder, surfaces, type, motion) and `docs/design/layout.md` (grid, header, pages). Where they disagree with the rules below, they describe the target; update this file when each piece ships.

Direction: Apple's Dynamic Island and the weather reference supplied by the owner on November 6, 2026.
Energy 1 / Rhythm 2 / Motion 2: quiet controls, content-led layouts, responsive transitions.

- Use a dark, near-black island by default because it belongs at the edge of the desktop. Preserve the user's light and custom themes.
- Use the Windows system variable font for legibility and reliable installation. Large, light temperature numerals lead weather; secondary readings use smaller, regular type.
- The island is the enclosing surface. Use subtle inset surfaces for selected controls and rows; avoid stacking decorative cards inside it.
- Use generous outer rounding, smaller control rounding, and a consistent 4/8-point spacing scale to distinguish the shell from its controls.
- Radius ladder: shell 34, card 22, control 14, chips and buttons full pills. In XAML write `{shell:Round}` (pill), `{shell:Round 14}` or `{shell:Round 22}`, never a bare number: WPF draws an oversized radius as an oval, and `shell:Round` clamps to half the shorter side. A test enforces this for module templates.
- Pages are composed from cards (`Island.Card`: inset surface, 22 radius, 14 padding, 10 gap). Home is a card grid: the month, or with the month off a large now-playing card with progress and transport, beside weather and timer, the running game and up-next cards. Media puts the player and the lyrics on separate cards.
- Type scale: 11 captions, 12 secondary, 13 body, 14 titles, 16 and 18 headings, 20 and 24 figures, 32 and up for display numerals. Do not add sizes between these. Helper text is for states that need action (a missing key, an empty list); never repeat what a control or shortcut already says.
- Use the chosen accent for selection and chart readings. Neutral text and surfaces carry the rest of the interface.
- The weather chart answers how precipitation, wind, or temperature changes across the selected day's hours. Plot only forecast data, preserve gaps, and expose exact values through pointer and keyboard selection.
- Weather follows the supplied composition: location and current temperature, condition and high/low, metric switch, hourly chart, daily forecast rows. Location editing and refresh belong in Settings, not the weather header.
- Calendar is its own tab: a month grid with calendar-colored event dots and a selected-day agenda. Home's month grid is a shortcut into it, not a second calendar implementation. Keep the calendar read-only; Join opens a meeting link without editing the event.
- The Launcher is one tab with Apps and Games sections. Start Menu apps are searchable; the Games section keeps game mode, the game library and the Minecraft server together.
- Timer is one tab with Timer and Pomodoro sections. The Timer section keeps the minute presets and the stopwatch; the Pomodoro section sets focus length, short break, long break and how many focus sessions come before a long break. Its start button names the focus length. The section switch sits centred on the clock line, and the panel grows to fit whichever section is showing.
- Tide is a local teleprompter tab: a script library, a reading line under the camera, speed presets, text size, mirror, optional voice follow and screen-capture hiding. Scripts stay on the PC; no account and no cloud.
- Tide's Listen section captures the microphone and system audio into a speaker-labelled transcript ("You" and "Others"), with a notes pane for the summary, action items and suggested replies. It is local speech-to-text: the transcript never leaves the PC, and the optional notes model is the only outbound call. No model is a clear state with a way into Settings, not an empty pane.
- Notes is one tab with Notes, Reminders and To-do sections. Notes are editable text, reminders are one-off timed alerts, and to-dos are a simple checklist. Keep each section quiet: one segmented switch, one input row and a short list.
- Files and Clipboard are separate tabs. Files is the shelf of paths; Clipboard is opt-in recent copies, saved on this PC and encrypted for the current Windows account.
- The Bluetooth header chip opens a small popover with connected devices and battery levels. The chip belongs with the other status chips, not inside the System tab.
- Side activities use attached capsules beside the main pill: two on each side, each with a module icon, a live label and a quiet module tint. One or two activities are round dots; three or four widen the non-numeric ones into capsules. Timer and agent plan usage stay circular rings: the timer shows time remaining, the Claude ring shows the percent of its fullest plan limit used (the same number as the Sessions list, never a Codex limit), and its tooltip names the limit. Surface tints identify the module; text stays neutral. Capsules disappear when the island opens.
- Laptops show battery in the header chip. A single warning appears at 20%; from 10% down the level stays in the pill until the laptop charges or rises above 10%. The battery switch is in Settings > Modules. A desktop with no battery has no battery chip, no low-battery pill and no battery setting at all.
- Frosted glass is one switch. The island is a shaped, translucent window, so the blur is sampled from the screen behind it and tinted with the background color; the tint stays a wash so the blur reads through. Sampling requires keeping the island out of screen capture, so glass hides it from screenshots and screen shares while it is on.
- Every enabled tab has three places in Settings: **bookmarked** (the star) keeps it in the header's top row, on-but-unstarred waits in the three-dot menu, and off removes it from both. Settings shows exactly one card per tab with two whole-tab controls: the star bookmarks the tab and the switch turns it off. Switches inside a card only fine-tune its parts and never carry stars. Bookmarks follow the Settings card order, so dragging a card reorders the top row. Choosing a tab from the three-dot menu opens it for that visit and puts it at the end of the top row, never in a bookmarked slot; its pin turns it into a bookmark. When every tab is bookmarked, the three-dot button disappears. Keep the same icon and name treatment in the menu as in Settings.
- The default top row is Home, Agents, Media, Notifications, Calendar, Files, Clipboard and Weather. Everything else ships on, in the three-dot menu.
- Games get their own Settings page: island behavior while playing, notification mute, performance and play-time readouts, start announcements, automatic detection, which libraries to scan, and the Minecraft server with its check interval. Keep each group short and independent.
- First run keeps the Settings chrome but leads with the island itself: a near-black stage showing the compact pill and side capsules, a top-row picker whose strip preview updates as tabs are starred, and a ready screen with that same strip. One decision per screen; skipping keeps the defaults and never leaves a tab off. The star is the only bookmark control: outline at rest, filled accent when pinned.
- Use sender icons for notifications, with a native bell fallback. The notification view must work independently of coding-agent templates.
- The command palette is one search surface over tabs, Start Menu apps, quick actions and timers. It opens over the panel body, keeps the header, starts with an empty query, and runs the selected row with Enter. Escape returns focus to the selected tab. A terminal action closes the island; opening a tab keeps it open.
- Do Not Disturb is one quiet mode. A timed ATOLL toggle lives on the moon chip, tray and command palette, and an optional setting mirrors Windows Focus. It silences notifications, agent-done, calendar, media and game announcements; permission prompts, timers and reminders still break through.
- Motion communicates opening, closing, and selection. Respect Windows reduced-motion settings; keep input available during transitions.
